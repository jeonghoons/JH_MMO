## 환경
- PC: i5-10400F(6코어 12스레드), 서버·봇 같은 PC, Release x64, 에디터 닫음, 비관리자 셸.
- 빌드: 작업 트리(P1a 지표 추가) + 직전 커밋 `cbda1f5`. 레벨 `Continent01`(504m, 몬스터 201마리), `RoomCapacity` 100(봇 100명마다 방 하나), `ViewAudit` 끔.
- 봇 인자: `--threads 4 --move-interval 200 --body male` + 시나리오별(`run_matrix.sh`). 핫존 = 마을 광장 `-14200,0,1000`(PlayerStart 반경 10m, 안전 구역 안 — 몬스터가 깨지 않음). 각 2회.

- 합격선(D-057): 틱 본문·지연 p99 ≤ 20ms, 핑 p99 ≤ 50ms, 봇 1명 수신 ≤ 64KB/s, 실패·`logDrop` 0.
