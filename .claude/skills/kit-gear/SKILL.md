# jm_kit 장비 도구 사용법

MCP `KitTools`(프로젝트 툴셋 `jm_mcp`)로 부른다. 메시 생성 요령은 `varco-gear` 스킬, 확인용 레벨 정리 규칙은 `pie-check` 스킬.

- `jm_kit` 기본: `kit_profiles.json`(체형별 리더·키트 부위·기본 의상, 슬롯별 숨김 부위), `preview`(테스트 레벨 `Dev/MC/L_KitTest`에 조립 `spawn`, SceneCapture `shot`/Simulate 중 `shot_game`, `look_at`). 예: `import importlib, jm_kit.preview as pv; importlib.reload(pv); pv.setup_level(); pv.spawn("KM", "M", (0, 0, 0), outfit="kit", anim=pv.ANIM["jog"])`
- `jm_kit.skeleton_check` — 장비 메시 뼈대 검사(MC1.3): `check(메시, "M", slot="top")`(기준 = 키트 의상 또는 리더, 다르면 `ok: False`와 이유), `self_test()`. 장비를 만들면 반드시 통과시킵니다.
- `jm_kit.garment` — 의상 맞춤(MC2.1): `import_fbx`(짧은 경로에서), `build(정적 메시, "M", "top", 출력 경로)` = 키트 의상 복제 후 형상·가중치·머티리얼만 교체(뼈대·바인드·PA 상속, 결과에 `skeleton_ok`·`limbs_ok`), `build_gloves`(틀 없음 — 오른손 맞춤·좌우 반전·몸 메시 복제), `build_gloves_kit_hand`(키트 손 형상 + `glove_paint` 무늬, ORM 포함 — 판금은 `M_Equip_PBR`, `fit.clean_cuff`면 손목 가장자리를 팔뚝 축으로 펴서 톱니 제거), 방패는 정적 부착 `fit: "shield"`(`hand_l`, `face_dir`·`face`·`up`으로 앞면·위 축, 손바닥에서 `gap_cm` — MC4.2f), 투구는 정적 부착 `fit: "helm"`(머리 상자 균일 배율·`yaw`, `attach.target_tris`면 가져올 때 `reduce_static_lods`로 LOD 3단계 축소 — 고폴리 생성용), `fit.clear_cm`(몸과 최소 거리 — 삼각형이 큰 판금 상의 사이로 몸이 비치는 것 방지), `static_attachment`(두건·무기 본 부착값), `build_item(키)`·`import_source`(items.json 기준), `measure`. `preview.spawn`의 outfit 값에 items.json 키(예 `"Cloth_Sword"`)를 쓰면 체형별 메시·정적 부착을 알아서 처리합니다.
- `jm_kit.icon` — 장비 아이콘(MC2.4): `shoot(키 목록)` = items.json 아이템을 같은 조명·각도(방어구 정면 3/4, 무기 45° 대각선, 장갑 오른손 손등)로 투명 배경 촬영 → `SourceArt/Icons/T_Icon_<Item>.png`(512²) + 아이템 폴더 `T_Icon_<Item>`, 확인 시트 `Saved/MCShots/icons_sheet.png`. 아이템별 각도는 items.json `icon`(`yaw`·`pitch`·`margin`). MCP 도구 인자로 선택 목록(`list[str] | None`)은 변환이 실패하므로 쉼표 문자열로 받습니다.
- `jm_kit.body_mask` — 몸 마스킹(2026-11-05): `build_mask("M"/"F")`(키트 몸 UV에 영역·거리 마스크 래스터화 → `SourceArt/Masks` PNG → `Character/Body/Masks`), `build_material()`(`M_Body_Masked`·`MI_Body_<M|F>`), `apply(컴포넌트, 체형, 파라미터)`. `preview.spawn`이 입은 슬롯의 마스크를 리더(= 보이는 몸, 키트 `Body_Combined`)의 몸 섹션에 자동 적용합니다.
- `jm_kit.item_table` — 데이터 테이블 생성(MC4.1): `export(write=True)` = `ItemTable.csv` 외형 열(`AttachSocket`·`AttachM`·`AttachF`·`Mask`·`HideHair`)과 `BodyTable.csv`를 `items.json`·`kit_profiles.json`에서 계산해 씀(MCP `item_table_export`). 이 열은 손으로 고치지 않고, 쓴 뒤 `reimport_csv`로 DT를 다시 채웁니다. 메시가 없는 행(`Slot` `None` — 소비 아이템)은 건너뜁니다(결과 `skipped`).
- 장비 폴더 구조(D-241, 2026-11-21 IT0): `Equipment/_Armor/Male·Female/<부위>/SK_<키>_<M|F>`, `_Armor/Unisex/Head/SM_<키>`, `_Armor/Source/<키>/`(원본 메시·M_·T_), `_Weapon/<OneHandSword|TwoHandSword|Bow|Shield>/SM_<키>`, `_Weapon/Source/<키>/`, `_Icons/T_Icon_<키>`, `_Shared/`(M_Equip_PBR·SM_Arrow). 아이템 키 = `<등급 두 자리>_<부위>`(예 `00_Top`, `00_OneHandSword`). items.json `out`은 `{body_dir}`(Male/Female)·`{body}`(M/F) 틀이고 정적 장비는 `src_dir`(재질·텍스처 폴더)를 따로 가진다 — 경로는 `garment.out_path(it, body)`·`garment.src_dir(it)`로만 만든다. 옮기기·진열은 `jm_kit.equip_layout`(MCP `WorldTools.world_step(name="", step="eq_…")`): `eq_plan`·`eq_move`·`eq_redirectors`(`roots`로 검사 폴더 지정)·`eq_tables`·`eq_unused`·`eq_delete`, 옛 판금 백업 `eq_archive_plan`·`eq_archive_move`·`eq_archive_items`·`eq_archive_dirs`(D-244 — `items.json`의 `"archived": true` 항목은 `garment.load_items()`가 기본으로 뺌), 03등급 재질 발광 `eq_glow_master`·`eq_glow {keys, params}`(부모 `_Shared/M_Equip_PBR_Glow`, 기본값 `garment.GLOW_DEFAULTS` — D-267), 진열 레벨 `eq_gallery`(`/Game/Dev/Gallery/L_GearGallery` — 세트마다 남녀 × 5자세, 둘은 대표 프레임에 멈춤) → `preview_start_simulate` → `eq_gallery_shots`(Saved/MCShots/gallery_*). 카탈로그 페이지는 `icon_shoot(import_assets=false)`로 PNG를 뽑은 뒤 `python -I -X utf8 .claude/skills/kit-gear/scripts/gear_catalog.py` → `UEClient/JM/Saved/Catalog/` → Artifact 게시(같은 파일 경로로 다시 게시하면 같은 주소). **레벨 에셋을 `duplicate_asset`한 직후 `load_level`하면 에디터가 World Memory Leaks로 죽는다** — 새 레벨은 `preview.setup_level(경로)`(템플릿)로. 무기·방패·머리 장비 위치의 사용자 맞춤(D-243): `eq_fit`(맞춤 레벨 `/Game/Dev/Gallery/L_GearFit`, 대상 라벨 `FIT_<키>_<M|F>_<attach|back>` — 사용자가 W·E·R로 옮김) → `eq_fit_save`(→ `items.json` `manual`, ItemTable 외형 열까지) → `reimport_csv` DT_ItemTable, 되돌리기 `eq_fit_reset {key, body, which}`. 자세는 에디터 화면에만 걸리므로 레벨을 다시 열거나 Simulate를 했으면 `eq_fit`을 다시 부른다(저장된 수동값으로 놓임). 머리카락을 숨기는 머리 장비는 attach `box: "head"`(머리카락 뺀 머리 상자 — D-246).
- `jm_kit.posed` — 자세별 측정·촬영(MC4.2e, MCP `posed_run`·`posed_grip_search`): 동작 프레임(`POSES` — 활·검 대기·당김·스킬 등)으로 캐릭터 자세를 잡고(loadout `shield`면 검 자세에 방패도 붙여 앞·뒤 촬영) 장갑·무기 관통(맨손 기준값 포함), 상의 어깨 뭉침(어깨 관절 반경 삼각형 넓이 비·위치·몸 안 비율)을 재고 상체·어깨·손을 촬영(`Saved/MCShots/MC42e_*`). 키트 상의 경로를 넣으면 기준값. `grip_search`는 손잡이 수직 평면에서 쥐는 위치(`items.json` `attach.offset`, 손 본 로컬)를 찾는다. 자세는 C++ `UAnimAssetBuilder::PoseComponentAtTime`(에디터 월드는 틱하지 않음) — 눈·이·헤어 같은 Leader Pose 팔로워는 에디터 월드에서 따라오지 않아 숨긴다.
- 무기·방패 소켓(D-247~D-249): 메시는 `jm_kit.weapon_norm`으로 정규화(손잡이 = 원점, 검·활 긴 축 +Z, 검 칼 면 법선·활 시위·방패 앞면 +X, 실제 크기) → items.json attach/back이 `fit: socket`(`WeaponSocket_R`·`WeaponSocket_L`·`ShieldSocket_L`·`BackSocket_Sword`·`BackSocket_Bow`·`BackSocket_TwoHand`), 부착 변환은 단위. 소켓 값의 기준은 `jm_kit/kit_sockets.json` — 스켈레톤 `SK_Mannequin`은 git 제외 키트라 새 PC·키트 재설치 뒤 `world_step` `sk_apply`, 사용자가 Persona에서 옮기면 `sk_export`. 스켈레톤 Sockets 목록은 Python에서 보호돼 `add_socket(소켓, True)`를 쓰는데 메시·스켈레톤 양쪽에 들어가므로 `Dev/Sockets/SKM_SocketCarrier` 통로로만 넣는다(`remove_socket`은 이름으로 양쪽을 지움). 새 무기: items.json에 예전처럼 attach(fit length/shield + length_cm·grip_frac 등) → `garment_import_source` → `wn_apply {keys}`(한 번만 — 이미 `fit: socket`이면 건너뜀). 무기 종류 구분은 부착 대상 이름 끝 `_r`/`_l`(`equip_layout._side`).
- 소켓 자동 맞춤(D-250): `world_step` `eq_gripm {body, weapon, kind: sword|bow|two_hand}`(손가락 감쌈 — 위치는 소켓 X·Y만 찾으므로 칼 축 위 위치는 먼저 `eq_hand_axis {body, weapon, frames: [[시퀀스, 초]]}`로 손바닥 z를 재서 `eq_gripm_check {…, delta: {t: [0, 0, z], tilt: [0, 0]}}`의 `socket_rel_bone`으로 옮김, D-273)·`eq_grip_shield {body, weapon, yz, tilt}`(팔뚝 접촉) → 결과 `socket_rel_bone_new`를 `kit_sockets.json`에 적고 `sk_apply {names: [소켓]}`(이름 없이 부르면 JSON의 모든 소켓이 스켈레톤을 덮음 — Persona에서 옮긴 값이 `sk_export` 전이면 사라짐). 눈 확인은 `eq_hand_shots {body, weapon, poses, sockets, label}`(소켓끼리 같은 구도 근접). 다른 체형·장갑은 `eq_gripm_check {…, delta}`·`eq_grip_shield_check`. 프레임은 `posed.GRIP_FRAMES`. 결과의 `at_search_edge`가 true면 범위(span·tilt·yz)를 넓혀 다시. 기울기는 관통으로 잘 정해지지 않는 경우가 많다(점수가 평평하면 0°). Persona 미리보기 에셋은 Python으로 못 단다(사용자가 소켓 우클릭 → Add Preview Asset).
